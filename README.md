# Mama Birthday Website

A romantic React/Vite birthday website for Mama.

## Run
1. Install Node.js.
2. In this folder run:
   npm install
   npm run dev

## Personalise
Open `src/main.jsx`.
- Replace the hero photo placeholder with your image handling later.
- Edit the `cuteThings` array.
- Edit the `memories` array / gallery.
- Replace the letter with your own final wording if desired.
- Add a legal music embed/link for "Forever" by P-Square rather than bundling copyrighted audio.

## Deploy
Build with:
npm run build

Then deploy the generated `dist` folder to Vercel/Netlify, or connect the GitHub repository to Vercel.
